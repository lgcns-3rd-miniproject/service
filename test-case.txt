
# ip는 aws gateway public ip 

1. Agent = 1
2. Vuser per agent = 99
3. Script 에 grinder.sleep(1000) 추가
4. Ramp-Up
  - Interval = 20000ms
  
한 번 종료된 후에 해당 컨테이너의 replica를 2로 올려서 같은 조건으로 실행 후, 이미지 첨부.



1. user
- 미리 한 번 회원가입을 한 후에 테스트를 진행할 것.
- http://<ip>:9000/api/v1/mini/user/1

2. restarea
- 미리 openapi에서 휴게소 업데이트를 한 후 테스트를 진행할 것.
- http://<ip>:9000/api/v1/mini/restarea/lists/restarea/1

3. food (restarea-unit)
- 미리 openapi에서 음식 업데이트를 한 후 테스트를 진행할 것.
- http://<ip>:9000/api/v1/mini/food/lists/1

4. facility (restarea-unit)
- 미리 openapi에서 편의시설 업데이트를 한 후 테스트를 진행할 것.
- http://<ip>:9000/api/v1/mini/facility/lists/1

5. review (content)
- http://<ip>:9000/api/v1/mini/review/lists/1

6. favorite (content)
- http://<ip>:9000/api/v1/mini/favorite/lists/1
